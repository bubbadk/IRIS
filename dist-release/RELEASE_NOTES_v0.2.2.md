## IRIS v0.2.2 — Performance Polish & Live Update Checker

IRIS v0.2.2 delivers clean strict typing, linter optimizations, and updates the built-in update notification client to track live GitHub releases from the official repository.

---

### ⚡ What's Changed in v0.2.2
- **Update Notification System**: Direct integration with `bubbadk/IRIS` release catalog to notify users of new versions in real-time.
- **Strict TypeScript & Linter Audit**: Cleaned all unused imports, replaced loose typings with strict record interfaces across tools and workflows.
- **Project Flow Reactor Improvements**: Enhanced reactivity in task matrix state rendering and inline approval dispatch.
- **Web & Multimodal Tools Stabilization**: Hardened API response validations for OpenAI DALL-E, OpenRouter Flux, and Firecrawl extraction.
