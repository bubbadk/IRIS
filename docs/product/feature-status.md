# IRIS feature status

Working-tree status, 2026-09-09. This is the full improvement list discussed with the user, not a claim that feature parity has been achieved. Release version remains 0.2.11.

| Area                       | Implemented in this work                                                                                                                                                                                                  | Still required                                                                                                                           |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |

| Documents and deliverables | Documents window, durable revision history, editing, static previews, agent document tools, original-format, Word, plain-text PDF, basic comma-separated-row XLSX and plain-text PPTX export                              | Rich presentation production, rich spreadsheet support, rich PDF layout and formatting beyond basic headings and bullets                 |

## Completion rules

An area is not complete merely because a component or backend exists. Its user flow must be connected, persistent, truthful about unavailable capabilities and verified with appropriate tests. Local builds and native startup checks are separate from publishing a release. No simulated activity may be used to fill missing runtime behavior.
