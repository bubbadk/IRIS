Keep the requested order: **quality control → services → channels → memory → browser → documents → onboarding/workflows → release**. Within quality control, fix the observed stale-evidence acceptance hole first: accepting an obsolete artifact invalidates any later semantic/test result too. This is a dependency refinement, not a claim that the broader quality layer is finished.

Independent semantic review needs explicit criterion coverage, bounded artifact context, provider permission/privacy policy and failure states. Automated test checks need the existing approval/isolation boundary, bounded command execution and real captured exit/output evidence. Plan adjustments depend on persisted review findings. Browser profiles precede their onboarding. Release acceptance follows tested source and approved publication.
