# IRIS Roadmap

This is directional, not a queue that must be followed blindly.

1. Visual desktop and object interaction foundation.
2. Provider registry and graphical provider configuration.
3. Agent genome/configuration model.
4. Tool registry and explicit permission policies.
5. First real agent runtime with streaming events.
6. Cortex routing, planning and context packs.
7. Memory subsystem with inspectable provenance.
8. Task graph and temporary worker agents.
9. Skills and reusable procedures.
10. Integrations, schedules and channels.
11. Release hardening, migration, backup and installers.
